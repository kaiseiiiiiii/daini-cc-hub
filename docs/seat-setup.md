# 座席表の取り込み（セットアップ手順）

座席表の原本から「その日の座席」を読み取り、アプリのシフトタブの先頭に出します。

- 夜（23時台）に **翌日分**を先取りします。翌朝の出社前に自分の席が分かる状態を作るためです。
- 朝（8時台）に **当日分**を取り直し、前夜と中身が変わっていないか確認します。
  変わっていれば画面に警告を出し、Chat にも流します。

GAS のコードは [`gas/seats.gs`](../gas/seats.gs) にあります。

---

## ⚠️ この機能だけ、ほかの同期と作りが違います

`sync.gs`（シフト・実績・目標）は、**自分が乗っているスプレッドシートしか開きません**。
原本は同期用スプレッドシート側の IMPORTRANGE が引いており、原本を書き換える経路が
仕組みとして存在しない、という作りになっています。

**座席表だけは原本を直接開きます**（`SpreadsheetApp.openById`）。理由は背景色です。

座席表には「※遅番グレー」「※青PCなし」という凡例が表の中にあり、**色そのものが意味を
持っています**。IMPORTRANGE は背景色を運ばないため、IMPORTRANGE 経由では早番と遅番の
区別が付かない座席表になり、実物と違うものを見せることになります。

その代わり、`seats.gs` は原本に対して**読み取りしか行いません**。使っているのは
`getValues()` と `getBackgrounds()` だけで、セルに書き込む呼び出しは1つもありません。
**このファイルを変更するときは、書き込み系のメソッドを足さないでください。**

---

## 1. 原本を同期用アカウントに共有する

座席表の原本を、**Apps Script プロジェクトを動かしているアカウント**に共有します。
権限は **閲覧者** で足ります（編集者にしないでください）。

原本の所有者が別の人の場合は、その方に共有を依頼してください。

## 2. ファイルIDをスクリプトプロパティに入れる

原本のURLがこの形のとき、

```
https://docs.google.com/spreadsheets/d/【この部分がファイルID】/edit#gid=0
```

Apps Script の **プロジェクトの設定 → スクリプト プロパティ** に追加します。

| プロパティ名 | 値 |
|---|---|
| `SEAT_FILE_ID` | 座席表の原本のファイルID |

> **ファイルIDはコードに書かないでください。** このリポジトリは公開されています。
> スクリプトプロパティはリポジトリに入りません。

## 3. コードを貼る

`gas/seats.gs` の内容を、Apps Script プロジェクトに `seats.gs` という名前で追加します
（`sync.gs` と同じプロジェクトに置いてください。認証まわりの関数を共有しているため、
単独では動きません）。

## 4. 権限を承認する

`seats.gs` は**ほかのスプレッドシートを開く**ため、これまでより広い権限が必要です。
初回実行時に承認画面が出るので、許可してください。

エディタで `checkSeatSetup` を選んで実行すると、承認画面が出たうえで設定状況が出ます。

```
OK     スクリプトプロパティ SEAT_FILE_ID
OK     座席表を開けました: 座席
OK     当日「8/16座席」 12行 × 6列 ／ 色付きセル 8個
--     翌日（8/17 座席）のタブはまだありません
未設定  トリガー（installSeatTriggers を実行してください）
```

「座席表を開けませんでした」と出る場合は、手順1の共有ができていません。

## 5. トリガーを設定する

エディタで `installSeatTriggers` を1度だけ実行します。

- `syncSeatsTonight` … 毎日23時台。**翌日分**を取り込む
- `syncSeatsMorning` … 毎日8時台。**当日分**を取り直し、前夜からの変更を確認する

> Apps Script の時間主導型トリガーは「◯時台」の指定しかできません。
> 実際に走るのは 23:00〜23:59 / 8:00〜8:59 のどこかになります。

## 6. 動作確認

`manualSeatSync`（当日分）を実行し、アプリのシフトタブを開いて座席表が出れば完了です。

## タブ名について

原本のタブ名は「8/12 座席」「8/16座席」のようにスペースの有無が揃っていません。
名前の完全一致では探さず、**タブ名から月日を拾って数値で突き合わせています**
（`findSeatSheet_`）。ゼロ埋め（`08/06 座席`）でも通ります。

条件は次の2つだけです。

- タブ名に「座席」が含まれている
- タブ名に `M/D` 形式の日付が含まれている

タブ名の付け方を変えるときは、この2つを外さないでください。

---

## 動かないときに見るところ

同期用スプレッドシートに **`_seat_log`** シートが自動で作られ、毎回の実行結果が残ります。

| 結果 | 意味 |
|---|---|
| `ok` | 取り込めた |
| `skip` | その日のタブが無い、または空だった（**異常ではありません**） |
| `error` | 失敗。内容の列に理由が入ります |

`skip` は休業日や、翌日分のタブがまだ作られていない日に普通に出ます。
`skip` のときは既に取り込んである分を消しません。

## データの形

| コレクション | ドキュメントID | 書き込み | 用途 |
|---|---|---|---|
| `seats` | `YYYY-MM-DD` | GAS のみ | その日の座席表 |

```
seats/2026-08-16
  date            "2026-08-16"
  label           "8/16座席"        … 元のタブ名
  cols            6
  rows            [{ cells: [{ t: "太田さん", b: "#d9d9d9" }, ...] }, ...]
  fingerprint     中身の指紋。朝の再確認で差分を見るのに使う
  syncedAt        取り込んだ時刻
  syncedBy        "night" | "morning" | "manual"
  checkedAt       朝の再確認をした時刻
  changedAtCheck  朝の再確認で前夜から変わっていたか
```

行を「配列の配列」にしていないのは、Firestore が配列の直下に配列を置けないためです。
`{cells:[...]}` を1枚かませてあります。

空セルも `{t:""}` として残します。**詰めると席の位置がずれる**ためです。

背景色は既定の白だけ「色なし」として捨てています。そのまま持たせると、ほぼ全セルに
色が付いた状態になって無駄が大きいためです。

---

## アプリ側の表示

- シフトタブの**一番上**に常時表示されます
- 翌日分が取り込まれていれば「本日 / 明日」で切り替えられます
- **自分の名前は枠と太字で強調**されます。原本の背景色は塗り替えません（色が遅番などの
  意味を持っているため）
- 名前はメンバーマスタと突き合わせていません。原本の表記が「太田さん」「洸太朗さん」
  「前田C」「金兒L」と揺れていて、機械的に対応付けると取り違えるためです。
  自分の強調だけ、姓・名・表示名のいずれかが含まれていれば拾う、という緩い判定にしています
  （1文字の語は使いません。「守」のような名前が「守衛室」に当たるのを避けるため）
